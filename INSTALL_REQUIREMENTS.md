# Required NPM Packages to Install

Run the following command to install missing dependencies:

```bash
npm install clsx tailwind-merge lucide-react
```

These packages are required for:
- `clsx` and `tailwind-merge` - Used in the Badge component for className merging
- `lucide-react` - Used for icons in search filters and other components

All other dependencies should already be installed per the package.json.
